🔁 Request Pipeline

Step-by-step lifecycle of an inbound HTTP request through the application stack. Click any step to see implementation detail.

1
HTTP request hits public/index.php (PHP built-in / Apache / Nginx)
▼
Laravel Application::configure bootstrap in bootstrap/app.php.
2
web middleware group runs (session, cookies, CSRF)
⚙️ Core Middleware ▼
CSRF excepted for stripe/* webhook paths.
3
HandleInertiaRequests shares auth/cart/flash/site props
⚙️ Core Middleware ▼
Makes $page.props available to all Vue pages.
4
Route matched from web.php / auth.php / admin.php
▼
admin.php loaded via withRouting(then:). Named routes via Ziggy on frontend.
5
auth / admin / super-admin middleware gates access
🔐 Security Middleware ▼
AdminMiddleware checks role; SuperAdminMiddleware restricts user management.
6
FormRequest validates input; Policy authorizes action
🔐 Security Middleware ▼
Controllers use $request->validated() and authorizeResource / authorize().
7
Controller delegates to Service; Eloquent persists
🔧 Core Services ▼
Thin controllers — business logic lives in app/Services.
8
Inertia::render or redirect()->route response
▼
Vue page receives API Resources — never raw Eloquent models.
